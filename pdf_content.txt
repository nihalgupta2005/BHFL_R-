MERN	Stack	Coding	Assessment
Stack:	MongoDB	·	Express	·	React	·	Node.js
Problem	Statement:	"DeskFlow"	—	A	Support	Ticket	Triage	Board
Build	a	support	ticket	system.	Customers	submit	tickets	with	a	priority.	Support	agents	see	a	board	grouped	by
status,	can	move	tickets	between	statuses,	and	each	ticket	tracks	how	long	it	has	been	open.	Tickets	that	exceed
their	response	time	target	are	flagged	as	breaching	SLA.
Objective
Test	your	ability	to	design	a	small	MERN	application	involving	derived	fields,	time-based	logic,	status	transitions
with	rules,	and	an	interactive	board-style	UI.

Compute	two	derived	fields	on	every	ticket	response:

slaBreached
	—	boolean.	True	if	a	ticket	is	still	unresolved	past	its	target,	or	if	it	was	resolved	after	its

Four	columns,	one	per	status:

Resolved

Each	ticket	card	shows	subject,	priority	(visually	distinguishable	—	colored	badge	or	similar),	age	(e.g.	"3h

Each	card	has	buttons	or	controls	to	move	it	to	an	adjacent	status.	Disallowed	transitions	should	not	be

Moving	a	ticket	must	update	the	board	without	a	page	reload.
Filters
Controls	above	the	board	to	filter	by	priority	and	to	show	only	SLA-breached	tickets.
Stats	Strip
A	small	strip	somewhere	on	the	page	showing	total	tickets	per	status	and	the	count	of	currently	breached
tickets,	fetched	from	the	stats	endpoint.
Create	Ticket
A	form	to	submit	a	new	ticket	(subject,	description,	customer	email,	priority).	On	success,	the	new	ticket
appears	in	the	appropriate	column	without	a	reload.
General
Handle	loading	and	error	states.
Show	inline	form	errors,	not	generic	alerts.
Styling	is	up	to	you	—	clean	and	functional	is	enough.	No	UI	library	required.
